# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1. Be kind, be respectful, assume good faith.

## Enforcement

Unacceptable behavior can be reported privately to the project maintainers
via the repository's
[private vulnerability reporting channel](https://github.com/TogetherWeOwn/two-bot-next/security/advisories/new)
(mark the report as a Code of Conduct matter, not a vulnerability).
Maintainers will review and respond, and may remove, edit or reject
contributions that violate this Code.
